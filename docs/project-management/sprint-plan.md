# Four-Sprint Plan

| Sprint | Goal | Key Deliverables |
|---|---|---|
| **Sprint 1** | Foundation & Authentication | User auth APIs (register, login, logout, me), frontend auth forms, session handling |
| **Sprint 2** | App Shell & Dashboard Foundation | Responsive layout, sidebar, user navigation, profile view |
| **Sprint 3** | Portfolio Management | Portfolio CRUD API & UI, user-level isolation, base currency |
| **Sprint 4** | Dashboard Integration & MVP Hardening | Dashboard overview API, TanStack Query sync, E2E testing, CI/CD validation |
