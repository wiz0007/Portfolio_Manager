# Product Roadmap

## Overview
A scalable, multi-asset portfolio management platform enabling users to organize, monitor, and analyze investments across different asset classes.

## Phase 1: Core Foundation & Portfolio Tracking (Sprints 1 - 4)
- **Sprint 1: Project foundation and authentication**
  - Custom User model, registration, login/logout, JWT/session handling, protected routes.
- **Sprint 2: Authenticated application shell and dashboard foundation**
  - Application layout, navigation, sidebar, user profile/account settings, session invalidation.
- **Sprint 3: Portfolio management**
  - Portfolio CRUD, ownership enforcement, multi-currency base reporting.
- **Sprint 4: Dashboard data integration and MVP hardening**
  - Aggregated dashboard overview metrics, TanStack Query integration, end-to-end testing and hardening.

## Phase 2: Holdings & Asset Tracking (Post-Sprint 4)
- Detailed asset modeling (stocks, mutual funds, crypto, gold, real estate).
- Transaction history (buy, sell, dividend, fee, deposit, withdrawal).
- Real-time/historical market data feeds.

## Phase 3: Financial Analytics & AI Intelligence
- Deterministic performance and risk engines (XIRR, Sharpe, VaR).
- OpenAI-powered portfolio analysis and natural-language summaries.
