# Sprint 4 — Correction & Stabilization Audit Map

**Document:** `docs/sprints/sprint-4-correction-map.md`  
**Purpose:** Pre-implementation architectural audit and correction matrix mapping identified financial calculation, data integrity, strategy registry, transaction ledger, projection engine, and frontend gaps to existing repository components.

---

## 1. Architectural Audit Overview

An exhaustive pre-implementation inspection of the current repository was performed across:
- `backend/apps/assets/models/` (`Investment`, `InvestmentTransaction`, `InvestmentValuation`, `details.py`)
- `backend/apps/assets/api/v1/serializers/` (`investment.py`, `details.py`, `detail_validators.py`)
- `backend/apps/valuation/services/asset_valuation/` (`base.py`, `cash.py`, `fixed_deposit.py`, `recurring_deposit.py`, `equity.py`, `mutual_fund.py`, `bond.py`, `gold.py`, `real_estate.py`, `crypto.py`, `__init__.py`)
- `backend/apps/valuation/services/` (`valuation_orchestrator.py`, `projection_engine.py`)
- `frontend/src/features/investments/` (`InvestmentEntryFlow.tsx`, `InvestmentDetailModal.tsx`, `HoldingValuationCard.tsx`, `financialCalculators.ts`, `investmentValuationApi.ts`)
